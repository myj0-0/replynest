# 账号与安全

## 忘记密码

1. 在[登录页](https://console.replynest.cn/login)选择忘记密码，提交注册邮箱。
2. 统一提示：“如果该邮箱已注册，我们会发送重置邮件；未注册的邮箱请先注册。”它保护账号隐私，未注册邮箱不会发送邮件。
3. 打开最新邮件，输入并确认新密码，再登录。不要转发重置链接或放入截图。
4. 链接失效、已用或超时则重新申请；失败时提供时间和脱敏提示，不发送新密码或完整链接。

## 团队与凭据

- 每位客服使用独立账号，不共用密码。
- 离职或岗位变化时及时调整成员权限。
- AppSecret、Webhook Token 和 API Key 不应通过聊天或截图传播。
- 发现异常登录、消息误发或凭据泄露时，先停用相关连接并轮换密钥，再联系支持。

系统状态可在 [status.replynest.cn](https://status.replynest.cn/) 查询。
