# 客服工作台与客户搜索

从页眉进入[答巢自研客服工作台](https://console.replynest.cn/workbench)。先确认企业，选择会话再回复，不需要跳转旧客服系统。

## 接待消息

左侧按全部、待处理、等待中、已解决选会话，中央看聊天，右侧看资料、负责人及备注。按权限认领、转派、更新状态。

“回复”向客户发送，“私人便笺”仅团队可见。AI 建议与自动草稿应核对来源、称呼及业务条件，不把便笺当作已对客户送达。

## 快捷键

- **Enter 发送，Ctrl+Enter 换行**；也兼容 Shift+Enter、macOS Command+Enter 换行。
- 中文输入法选词时 Enter 不发送。
- 输入 `/` 查快捷回复，列表中的 Enter 先选择，不直接外发。
- 快捷回复“管理”跳转知识库管理页，普通坐席不因此获得编辑权限。

## 搜索客户与消息

输入姓名、电话、邮箱、客户备注并搜索。展开高级搜索，可加消息内容及最后活动日期；多个条件须同时满足，日期按北京时间，结束日期包含整天。

“继续查找更早的会话”表示仍有未扫描历史，不把当前空页当作全库无结果。修改条件重新开始查询。内容检索不包含图片识别或附件全文；私人便笺可能参与搜索，不直接公开搜索截图。

## 与 AI 协作

可以对客户“暂停 10 分钟”或“提前恢复”，作用于当前客户在本企业的会话。仅转派人工不停止 AI，到期只处理新问题。详见[接待模式](automatic-reception.md)。

管理员发布工坊应用并添加到工作台后，坐席按权限用表单和工具，自定义受控布局。读取客户字段与意图分类独立授权；模板不覆盖登录、权限或发送确认，见[工坊参考](platform-bricks.md)。

未接入渠道先[设置入口](wechat-official.md)。会话服务不可用时查[系统状态](https://status.replynest.cn/)并刷新，持续异常记录企业和时间联系支持。
