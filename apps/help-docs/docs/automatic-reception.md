# AI 接待模式、语气与历史学习

入口：[企业设置](https://console.replynest.cn/settings/communications)。管理员选择模式；渠道、知识和发送授权仍需分别准备。

## 三种模式

| 模式 | AI 做什么 | 谁发送 |
| --- | --- | --- |
| 人工辅助 | 坐席按需生成建议 | 坐席核对并点击发送 |
| 自动草稿 | 符合条件的新问题生成团队可见草稿 | 坐席核对后发送，草稿不直接外发 |
| 自动接待 | 检索已发布有效知识，生成并独立核验来源 | 已授权渠道中通过来源、风险和阈值检查的回答自动发送，其他交人工 |


## 开启知识库自动接待

1. 先准备[已发布并完成索引的知识](knowledge-copilot.md)，用人工辅助检查回答质量。
2. 选择“自动接待”，核对最低依据置信度，保存模式并阅读确认。分数用于筛选，不是回答正确率保证。
3. 打开“管理知识库接待”，分别阅读并保存网站聊天和公众号发送授权；公众号只勾选要接待的独立或共享渠道。
4. 刷新检查**模式、授权和执行服务状态**。保存授权不代表服务启用；提示尚未开放或状态未确认时先查状态。
5. 用自己有权测试的客户账号发一个新问题，检查客户端效果，再到[扣费详情](https://console.replynest.cn/billing/history?view=reception)核对执行与点数。

不需要逐条批准精确问题样例，而是从知识库回答相近问法。来源不足、条件缺失、知识冲突、高风险或低于阈值时转人工；不保证任意长文都能自动回答。检索、生成、核验已经发生的实际用量，即使最终不发送也可能计费。

分配人工**不会单独停止 AI**。工作台可对客户“暂停 10 分钟”或“提前恢复”，作用于该客户在本企业的会话。到期只处理新问题，不补发暂停期间内容，也不重复回复人工已经回答的问题。

共享公众号仅接待当前明确咨询本商家的用户，答复标明商家；授权不包含营销群发。微信窗口、频率和权限限制仍适用。

## 语气与回复节奏

在“知识库自动接待 → 接待语气与回复节奏”分别选择自动草稿和接待语气：**简洁直接、标准中性、亲切详细**。它改变表达，不增加未经知识验证的承诺。

默认延迟下限 1 秒、上限 30 秒，可调整或关闭；从收到新问题起算，字数越多越接近上限，节奏函数不达到上限。模型、队列与渠道耗时可能导致实际收到更晚，并非“30 秒内送达”保证。人工发送和团队可见草稿不等待。

用户端 AI 标识按页面选项配置，不授予发送权限，也不替代适用的生成内容告知义务。客服工作台仍保留“答巢自动接待”来源及内部记录。

## 历史用途独立授权

| 用途 | 作用 | 边界 |
| --- | --- | --- |
| 当前客户历史上下文 | 读取本企业当前客户近 30 天的有界公开聊天 | 不读取其他客户、便笺或已删除记录，不把历史当作已核实政策 |
| 学习人工回复语气 | 统计近期人工公开回复的称呼、句长和表情特征 | 不学习业务事实，不把原文与人员标识当作语气提示传给模型 |
| 历史聊天生成知识草稿 | 从客户问题与对应人工答复整理带来源草稿 | 不自动发布，不授权发送，须人工核对 |

逐项阅读、确认，可单独撤销。模仿人工表达还应勾选“参考本企业常见人工语气”，不能只保存用途授权。

点击“生成待核对知识草稿”查看任务，每次最多整理 5 条。核对过期、冲突、隐私与错误承诺，编辑再确认发布。生成及后续索引按实际调用消耗点数。

## 没回复怎么查？

新问题是否收到 → 模式和对应授权 → 知识发布与索引 → 客户暂停或人工已答 → 点数与服务状态 → 来源、风险、阈值 → 渠道发送结果。

平台或微信受理不代表客户已读；不确定时查执行记录，不盲目重试。撤销阻止新处理与提交，已提交请求可能完成，不能撤回已到达客户端的消息。
