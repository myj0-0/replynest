# 快速开始

先打通一条人工接待链路，再启用 AI；不需要一次填完所有设置。

## 五步开始

1. 在[控制台](https://console.replynest.cn/login)登录，确认左上角当前企业；多个企业时先切换。
2. 选择[共享或独立公众号](wechat-official.md)，或[网站聊天](website-chat.md)入口。没有渠道时工作台无会话属于正常情况。
3. 从客户入口发测试消息，在工作台选择会话、人工回复并确认客户端收到，见[工作台教程](agent-workspace.md)。
4. 准备[知识库与快捷回复](knowledge-copilot.md)，或先领取[模板](template-market.md)再改为真实业务口径；邀请成员并设置[通知](notifications.md)。
5. 根据需要选择[人工辅助、自动草稿或自动接待](automatic-reception.md)，分别核对模式、知识和渠道授权。

注册试用与赠送额度以账号当前页面为准。余额、AI 点数及购买入口见[套餐与账务](billing.md)。

## 控制台与客服工作台

- **运营控制台**：接入渠道、管理知识与规则、邀请成员、查看套餐和审计记录。
- **客服工作台**：接待客户消息、查看 AI 建议、编辑并发送最终回复。

点击页眉的“进入客服工作台”即可在相同企业身份下进入会话页面。不要共享个人账号；请为每位成员创建独立账号，确保审计记录可追溯。
