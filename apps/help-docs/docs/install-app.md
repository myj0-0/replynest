# 安装答巢应用（PWA）

答巢 PWA 是可直接从浏览器安装的客服应用，无需经过应用商店。安装后可从电脑桌面、开始菜单或手机主屏幕快速进入客服工作台，并继续使用同一答巢账号与企业工作区。

## 安装前须知

- 安装应用不会自动开启消息通知。通知权限只会在您主动点击“启用浏览器推送”后申请。
- 客户会话、租户页面和 API 数据不会写入离线缓存。断网时只显示离线说明，恢复联网后才能继续处理消息。
- 请从 `https://console.replynest.cn` 安装，避免从仿冒页面添加快捷方式。
- 控制台右上角始终提供“安装应用”入口。企业完成有效渠道接入后，控制台也会显示一次安装建议；选择“暂不”后不会反复打扰。

## Windows / macOS / Linux

推荐使用最新版 Chrome 或 Edge：

1. 打开[答巢运营中心](https://console.replynest.cn/login)并登录。
2. 点击右上角“安装应用”。如果浏览器提供系统安装窗口，选择“安装”。
3. 如果没有弹出安装窗口，请打开浏览器菜单，选择“安装答巢”“安装应用”或“创建快捷方式”。
4. 安装完成后，可从桌面、开始菜单、程序坞或应用列表启动答巢。

部分浏览器不会提供原生 PWA 安装能力。遇到这种情况，请改用 Chrome 或 Edge。

## Android

1. 使用 Chrome 打开[答巢运营中心](https://console.replynest.cn/login)。
2. 点击控制台右上角“安装应用”，或打开 Chrome 菜单。
3. 选择“安装应用”或“添加到主屏幕”，然后确认。
4. 从主屏幕打开答巢。若需要后台消息提醒，请登录后前往“通知中心”，再主动启用浏览器推送。

不同手机厂商的菜单名称可能略有差异。建议同时允许浏览器后台运行，否则系统省电策略可能延迟通知。

## iPhone / iPad

iOS 不允许网页直接弹出系统安装窗口，请使用 Safari 手动添加：

1. 使用 Safari 打开[答巢运营中心](https://console.replynest.cn/login)。
2. 点击 Safari 工具栏中的“分享”按钮。
3. 向下滚动并选择“添加到主屏幕”。
4. 确认名称后点击“添加”，再从主屏幕启动答巢。
5. 如需消息提醒，请从主屏幕打开已安装的答巢，登录后前往“通知中心”启用浏览器推送。

如果看不到“添加到主屏幕”，请确认当前页面由 Safari 打开，而不是微信、企业微信或其他应用内置浏览器。

## 更新与卸载

答巢会在联网时自动获取新版应用资源。发现界面未更新时，可完全关闭应用后重新打开，或在页面中刷新一次。无需重新安装，也不要通过清除站点数据来处理普通更新问题，因为清除数据会退出登录并移除本机通知订阅。

卸载方式与普通应用相同：电脑端从系统应用列表或浏览器应用管理页卸载；手机端长按答巢图标并选择移除。卸载 PWA 不会删除企业账号或云端业务数据。

## 常见问题

### 安装后是否可以离线回复客户？

不可以。为避免在共享设备上留下客户信息，也为了保证会话状态准确，客服消息仍需联网读取和发送。

### 安装后为什么没有消息通知？

安装与通知是两项独立授权。请打开控制台“通知中心”，点击“启用浏览器推送”，并在浏览器或系统权限窗口中允许通知。详情参见[通知与提醒](notifications.md)。

### 多名客服是否可以各自安装？

可以。每位客服都应使用自己的答巢账号，并在自己的受控设备上安装。请勿多人共用账号或浏览器配置文件。
