# 欢迎使用答巢 ReplyNest

答巢把公众号会话、企业知识、临时规则、AI 推荐回复和团队提醒连接到同一个客服流程中。

可选择人工辅助、自动草稿或知识库自动接待。自动接待须由管理员选择模式并逐渠道授权，未授权不会自动发送；知识不足、高风险或不确定的问题仍交人工。

## 从这里开始

1. 阅读[快速开始](getting-started.md)，了解控制台与客服工作台的分工。
2. 按[微信公众号接入](wechat-official.md)配置回调。
3. 准备[知识库与快捷回复](knowledge-copilot.md)，选择[AI 接待模式、语气与历史学习](automatic-reception.md)。
4. 按设备类型[安装答巢应用](install-app.md)，从桌面或手机主屏幕快速进入客服工作台。
5. 了解[客服工作台](agent-workspace.md)、[模板市场](template-market.md)和[套餐与账务](billing.md)。
6. 阅读[AI 定制工坊参考](platform-bricks.md)，了解表单、图表、受限计算、轮班和工作台配置。

需要协助时，可前往[联系客服](https://replynest.cn/contact)，也可发送邮件至 `support@fs.replynest.cn`。
