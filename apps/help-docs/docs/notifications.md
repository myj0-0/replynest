# 通知与提醒

答巢可通过浏览器推送、飞书、钉钉、企业微信和自定义 Webhook 提醒团队处理待回复会话。

建议先使用“长时间未处理”策略，避免每条消息都推送造成通知疲劳。请按班次设置升级时间，并定期测试通知目标是否仍可用。

## 通知中心与消息与活动

通知中心提醒团队处理消息、超时会话或服务异常；消息与活动用于对客户发送运营任务。团队通知不授予客户群发权限。营销群发仅适用于满足权限及套餐条件的独立渠道，共享公众号不支持。

## 设置提醒

1. 进入[通知中心](https://console.replynest.cn/notifications)，查看活动和未读通知。
2. 设置通知渠道、外部最低级别、静默时段、时区与未确认升级时间。
3. 选择客户消息策略，推荐“长时间未处理”，设置分钟数并保存。
4. 浏览器推送需本人点击启用并允许权限；iPhone/iPad 先添加到主屏幕，再从应用启用，见[安装教程](install-app.md)。

站内通知始终开启。企业微信应用通知暂未开放，不等于下方的企业微信群机器人。

## 机器人与 Webhook

选择飞书、企业微信、钉钉或自定义 HTTPS Webhook，填写名称及地址。可选 HMAC 密钥仅用于自定义 Webhook；机器人地址常含 Token，应当作凭据。钉钉通知固定包含关键词 `ReplyNest`，机器人关键词须匹配。

消息预览默认关闭；开启后最多 120 字客户消息可能发送给第三方目标。先核对处理目的、群成员及企业隐私要求，不发到无关群。截图和求助隐藏 Token 与密钥，仅保留域名。
