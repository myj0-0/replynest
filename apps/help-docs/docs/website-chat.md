在控制台「渠道与接入」的「网站聊天」中，企业管理员填写网站客服名称和 HTTPS 网站地址，创建渠道后复制嵌入代码，放在网站 HTML 的 `</body>` 前。无需在网页中填写 API 密钥。


首版每个企业支持一个网站聊天渠道，计入套餐渠道数量。网站地址用于展示配置，不是域名鉴权或访问白名单。网站标识是公开的，不应当作密钥使用。

## 测试消息闭环

1. 点击「打开访客测试页」，或打开已经插入代码的网站。
2. 点击右下角聊天气泡，发送一条不含敏感信息的测试消息。
3. 在答巢客服工作台刷新会话列表，打开该访客会话。
4. 人工回复，并返回访客页面确认收到消息。
5. 私人便笺只供团队内部使用，不会展示给访客。AI 推荐需要人工采用、核对并点击发送；接入网站不会自动打开 AI 自动回复。

浏览器中的访客会话依赖该浏览器的站点数据；清理数据、隐私模式或更换设备可能成为新访客。不要把聊天组件中自行填报的名称当成已认证身份。涉及订单等敏感业务时仍须验证客户身份。

## 网站部署注意事项

- 确保网站能够加载嵌入脚本以及客服站点的脚本、iframe、HTTPS 和 WebSocket 连接。严格 CSP、广告拦截器或网络限制可能阻止加载。
- 请在网站隐私说明中披露客服聊天数据处理方式，不要通过未签名的前端脚本传入敏感客户身份。
- 接入使用现有网页聊天引擎，不需要重新部署租户网站后端。
- 配置失败时先刷新查看结果再重试；系统使用固定收件箱标识进行恢复，避免反复创建重复渠道。

本期不包含登录用户身份签名接入、多网站独立收件箱或域名白名单管理。

准备知识与选择接待模式见[知识库](knowledge-copilot.md)及[自动接待教程](automatic-reception.md)。
