# 微信公众号接入图文教程

没有自己的公众号，可以使用答巢官方共享公众号；已有自己的公众号，则选择独立接入。两种渠道都在[渠道与接入](https://console.replynest.cn/channels)设置。


## 1. 先选接入方式

| 方式 | 需要准备 | 客户入口 | 限制 |
| --- | --- | --- | --- |
| 官方共享公众号 | 答巢企业管理员账号、商家介绍 | 本商家二维码，或在公众号切换商家 | 客户须明确选择商家；回复标明商家；不支持共享渠道营销群发 |
| 企业独立公众号 | 公众号管理权限、AppID、AppSecret 和所需接口权限 | 关注企业自己的公众号并发消息 | 受公众号类型、认证状态、接口权限和微信回复窗口限制 |

独立接入不是小程序接入，也不是把网站地址填进公众号菜单。先在[微信公众平台](https://mp.weixin.qq.com/)确认能配置消息回调并使用所需客服消息接口；认证通过不代表拥有全部接口权限。

## 2. 路径 A：官方共享公众号

1. 登录控制台，确认左上角**当前企业**，打开“渠道与接入”。
2. 在“官方共享公众号”区域填写商家介绍，可选填写 HTTPS 商家网站。介绍会向客户公开，请写服务范围和咨询方式，不放内部信息。
3. 网站或海报入口使用**长期商家二维码**；短期联调可用临时二维码。有效期以页面提示为准。
4. 用微信扫码并关注，确认当前咨询商家是您的企业。
5. 发一条普通测试文字，在[客服工作台](https://console.replynest.cn/workbench)确认进入正确企业，再人工回复，检查微信是否收到带商家名称的答复。

长期二维码是公开商家入口，不是后台登录凭据。撤销会阻止新扫码进入，不删除已有会话。刷新后图片隐藏，也不等于撤销。

:::tip 找不到消息？
在微信使用“切换商家”确认当前商家。仅关注公众号、扫码普通无商家参数二维码或搜索公众号名称，不能证明已选择您的商家。
:::

## 3. 路径 B：企业独立公众号

### 第一步：生成参数并保存公众号密钥

在“渠道与接入 → 微信公众号”点击**生成公众号接入参数**，取得完整回调 URL、Token、43 位 EncodingAESKey。接着填写并保存本公众号的 AppID 和 AppSecret。

只有企业管理员应处理密钥。不要将 AppSecret 放进客服聊天、知识库、AI 需求描述或公开截图。

### 第二步：在两侧填写对应参数

| 参数 | 来源 | 填到哪里 | 注意 |
| --- | --- | --- | --- |
| AppID | 微信公众号开发信息 | 答巢公众号密钥表单 | 必须属于本次接入的公众号 |
| AppSecret | 微信公众平台，由管理员查看或重置 | 答巢公众号密钥表单 | 不是小程序或开放平台应用密钥；重置后同步更新 |
| URL | 答巢生成的完整回调地址 | 微信消息/服务器配置 | 不是官网或工作台地址；不能截掉路径 |
| Token | 答巢生成的回调 Token | 微信消息/服务器配置 | 两侧逐字一致；不是 access_token |
| EncodingAESKey | 答巢生成的 43 位值 | 微信消息/服务器配置 | 两侧一致，不在微信单独生成另一份 |

在微信公众平台找到开发信息及消息/服务器配置入口，填写后三项，选择相符的消息加密方式。答巢支持加密消息，建议采用加密配置；不要为试通随意降低安全设置。微信菜单可能调整，以当前后台为准。

如微信要求 **IP 白名单**，向[答巢客服](https://replynest.cn/contact)取得当前接入服务出站 IP。不要填自己电脑的 IP，也不要根据回调域名猜测出站 IP。

### 第三步：微信保存、验证并启用

确认答巢已保存正确 AppID/AppSecret，再在微信提交配置，完成服务器验证并启用消息接收，回到答巢刷新。

**密钥已保存不等于微信回调验证或真实收发成功。** 已连接其他客服系统时，切换消息服务器会影响原系统接收；安排切换窗口并保留原配置用于恢复。

### 第四步：验证真实消息闭环

1. 用有权测试的微信账号关注企业公众号，发唯一测试文字，例如“接入测试 1008”。
2. 在工作台确认客户、消息时间及正文，避免误看旧记录。
3. 人工发送低风险回复，确认微信收到。
4. 需要 AI 接待时再准备知识并授权，见[自动接待教程](automatic-reception.md)。**接入渠道不会自动开启 AI 发送。**

## 4. 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 服务器验证失败 | 核对完整 URL、Token、AESKey、AppID 和保存状态，不反复生成参数；仍失败提供脱敏错误码与时间 |
| 配置成功但无消息 | 确认启用了消息接收、公众号与企业正确、旧客服系统不再接收；发一条新测试消息 |
| 能收但回复失败 | 核对 AppSecret、客服接口权限、IP 白名单、回复窗口及频率限制；结果不确定先核对，不盲目重发 |
| 重新生成后失效 | 旧回调参数会失效，须同步更新微信后台 |
| AI 没有回复 | 查知识发布与索引、模式与渠道授权、点数、客户暂停、来源风险和阈值；去账务详情看执行结果 |

微信客服消息常见回复窗口为客户交互后 48 小时，具体可用接口和条件由微信决定；答巢不能绕过限制。“微信已受理”不代表客户已读。
