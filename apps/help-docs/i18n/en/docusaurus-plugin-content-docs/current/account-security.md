# Account security

## Password reset

Use Forgot password at [Login](https://console.replynest.cn/login). The generic response says registered emails receive a reset message and unregistered users should sign up; unregistered addresses receive no reset email. Open the latest link, enter/confirm your own new password and sign in. Do not share links/passwords. Request a new link if expired/used; report redacted errors and time to support.

- Give every agent an individual account.
- Review access when roles change or people leave.
- Never share AppSecrets, webhook tokens, or API keys in chat or screenshots.
- If a credential may be exposed, disable the connection, rotate the credential, and contact support.

Check [service status](https://status.replynest.cn/en) for current availability.
