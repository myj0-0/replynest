# Support workspace and search

Use the header link to the [ReplyNest workspace](https://console.replynest.cn/workbench), confirm business and select a conversation. The legacy portal is not required. Filter states on the left, read centrally and inspect details on the right. Claim, assign and change status according to permissions. Reply is customer-facing; private notes are team-only.

Enter sends; Ctrl+Enter, Shift+Enter or macOS Command+Enter insert breaks. Input-method composition does not send. `/` searches quick replies; Enter selects a phrase rather than sending. Management links to Knowledge without granting editing rights.

Search name, phone, email or customer notes. Advanced search adds message text and last-activity dates, combining conditions; Shanghai dates include the whole end date. Continue older-history searches when offered: an empty page is not proof of no match. This is not attachment/OCR search; private notes may participate, so do not publish search screenshots.

Pause AI for ten minutes or resume early; assignment alone does not stop reception. [AI Studio](platform-bricks.md) provides approved tools and controlled layouts without overriding login, consent or sending controls. No channel: connect one first. Service unavailable: check [status](https://status.replynest.cn/) and report business/time if persistent.
