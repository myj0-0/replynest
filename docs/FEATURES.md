# 当前功能与授权

官网：[replynest.cn](https://replynest.cn/)。完整用户教程位于 [在线帮助](https://docs.replynest.cn/) 及仓库中的 `apps/help-docs/`。

| 模块 | 能力 | 主要边界 |
| --- | --- | --- |
| 渠道 | Web Chat、共享／独立公众号、商家路由与媒体收发 | 渠道 AppID、接口资格、接收／发送开关各自配置 |
| 工作台 | 会话、分配、未读、头像、搜索、客户资料、图文快捷回复 | 按企业／成员权限，接口接受发送不等于客户已读 |
| 知识 | 在线／上传文档、长短期分类、有效期、范围、版本与到期提醒 | 当前发布且匹配的来源才可检索；高风险知识需人工确认 |
| AI 接待 | 建议、自动答复、独立核验、人工转接与暂停 | 企业授权、渠道范围、风险、余额／预算及发送限制 |
| 客户画像 | 增量及跨会话备注、当前问题、需求／偏好统计 | 默认关闭、单独用途授权、每日预算、不覆盖人工备注 |
| 工坊 | 分流、排班、知识读取、外部接口与事件／定时工作流 | 预览不执行；绑定坐席与单独执行授权后才能真实转派／外发 |
| 组织与安全 | 角色邀请、权限菜单、隐私申请审核、账号安全日志 | 默认最小权限，后台身份复核，日志按部署保留策略清理 |
| 账务 | 套餐、生效日点数周期、续费／升降级／退款及返佣 | 旧单价格快照、幂等账本、退款扣回和风控不能由客户端决定 |
| 通知／API | 签名 Webhook、通知测试与正式投递、外部应用接入 | 临时错误有界重试，永久错误／不确定结果不能盲目重发 |

自部署不会自动获得官方托管服务的套餐、点数、渠道资格或其它租户的数据。源码中的模拟、预览、合成演示和真实执行入口有意区分，不通过修改页面文字绕过服务端校验。

当前文档仅描述已经存在的代码能力，不承诺所有第三方渠道已经商用开通，也不承诺未配置 Provider 的 AI、短信或支付能直接使用。
